# 记工 · 版本更新日志

## v1.0.2 | 2026-11-26

### 客户

· 新增「客户」模块：名称、分类（可选可输新分类）、联系人、电话、地址、备注；有结算单的客户不可删除。
· 列表显示未结应付 / 未结已收 / 未结款 / 未结单数，顶部汇总合计。
· 「已收」登记收款：按最早未结的结算单依次冲抵已收金额，超出部分自动顺延到下一单；超额收款会被拒绝。
· 收款记录可查看；未结款只统计没点已结的结算单，点已结即从应付/已收中扣除。

### 报价单

· 新增「已完成」：点击后不再出现在结算单的「按报价单结算」列表里。
· 客户可下拉选择（来自客户模块），也可以直接手输，默认空。

### 结算单

· 新增「按报价单结算」：选中报价单后自动带入项目、承包方式、客户与全部明细。
· 已收改为累加输入：每次填多少就加多少，可填负数冲减。
· 已收记录完整留痕（手动登记 / 客户收款冲抵 / 建单），支持逐条编辑与删除，按差额同步已收金额。
· 已结后禁止修改已收金额与已收记录。
· 结算单已收默认 0（不再默认等于应付），客户欠款才能真实反映。
· 「实收」统一改名为「已收」。

### 修复

· 修复未选客户时报价单/结算单列表报错（customer_id 为 NULL 的处理）。
· 修复新增报价单缺少参数的问题。


## v1.0.1 | 2026-11-22

### 在线更新

· 设置页新增「检查更新 / 一键更新」：下载、校验 sha256、替换运行目录后自动重启，数据不受影响。
· 更新源优先自有网关，网关不可用时回落到 GitHub Releases。
· 修复更新包解压失败：改为按文件头识别 zip / tar.gz，不再依赖文件后缀。

### 测试版通道

· 连续点击「当前版本」3 次解锁测试版通道，可检测并更新测试版。
· 测试版只从自有网关获取，不发布到 GitHub；正式版号更高时可平滑回到正式版。

### 结算单

· 新增「编辑」与「已结」：已结后编辑按钮置灰，后端同时拒绝修改，避免误改已结账单。
· 列表新增状态列（已结 / 未结）。

### 稳定性与体验

· 登录态改为存 SQLite（30 天有效），在线更新或重启后不再掉登录。
· 设置页新增「版本更新日志」，按正式版记录改动，默认展开最新一条。
· 修复设置页若干样式问题（版本号与日期间距、测试版区块边框）。


## v1.0.0 | 2026-10-31

### 记工与工人

· 记工支持「一天 / 半天 / 加班」：一天=1、半天=0.5、加班按小时单独统计不计天数，同一天可「一天+加班」叠加。
· 同一工人 + 同一工地合并为一条，按总天数统计；支持批量记工（多选工人 × 多选日期）。
· 工人资料含内部单价（记工成本）、对外单价（报给客户）、加班单价；工资结算后归档冻结，新记工重新累计。

### 价格与进料

· 价格明细分三套价目：材料价格、施工价格（包工包料）、施工价格（包工），施工价含同行价与客户价。
· 分类可自定义、可筛选；进料登记从价目表下拉带价，新材料自动入价目表。

### 报价与结算

· 报价单：项目名称自由填写 + 承包方式 + 报价类型（客户 / 同行），明细支持材料 / 包工包料 / 包工三级选择。
· 结算单：点工可从记工自动汇总工数，支持登记实收金额。
· Excel 导出（含人民币大写、盖章签字行）。

### 部署

· 支持 Linux x86_64 / ARM64 / Windows，飞牛 fnOS 原生 fpk 安装包，Docker Compose 一键部署。
· 数据只存本机 SQLite（data/jigong.db），备份该目录即可。
